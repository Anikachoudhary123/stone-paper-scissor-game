 Rock Paper Scissor Game

A simple command-line based Rock Paper Scissor game developed using Python. This project allows the user to play against the computer, where the computer generates its choice randomly.

The game compares the user's choice with the computer's choice and displays the final result, including win, lose, or tie conditions.

## Features
- Interactive user input
- Random computer-generated choices
- Result evaluation logic
- Tie condition handling
- Beginner-friendly Python project

## Technologies Used
- Python
- Random Module

## Game Rules
- Rock beats Scissor
- Paper beats Rock
- Scissor beats Paper
